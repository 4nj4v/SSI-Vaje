# 🛡️ Strežniški sistemi — Vaje (VSS, RII, 48 ur)

Repozitorij vsebuje komplet praktičnih vaj za predmet **Strežniški sistemi** (VSS, RII), namenjen študentom programa Računalništvo in informatika (RII).  
Vaje pokrivajo bistvene elemente dela v Linux okolju: delo v ukazni lupini, upravljanje datotek, pravice, arhiviranje, Bash skripte, administracijo uporabnikov ter osnovno strežniško konfiguracijo.

Vsaka vaja se nahaja v svoji mapi, znotraj katere je datoteka **README.md**, ki vsebuje:
- uvod v temo,  
- cilje vaje,  
- opis posameznih korakov,  
- primere ukazov,  
- dodatne naloge,  
- vprašanja za razmislek.

- Praktično delo v Linux terminalu
